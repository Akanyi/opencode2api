# 代理池与今日统计

基于上游 v1.4.1 的本地扩展。配置示例：

```json
{
  "proxies": [],
  "proxyfile": "proxies.txt",
  "proxyfiles": ["proxies-extra.txt", "proxies-export.csv"],
  "proxy_strategy": "affinity"
}
```

路径相对于 config.json 所在目录。旧 proxyfile、proxyfiles 与手填 proxies 合并并去重；文件缺失或配置的文件全部为空时，保存失败，不切换为直连。只有完全未配置代理时沿用原版 direct 默认值。URL 列表支持注释、BOM、pool+ 与 #pool；CSV 支持 URL/proxy/proxy_url，或 IP/Host/Server/Address、Port、User/Username/Login、Pass/Password 列，可选 Scheme/Protocol/Type。

控制台配置中心支持一次选择多个 TXT/CSV/LIST 文件，解析后加入新增代理编辑区；点击保存才写入配置并热应用。该导入方式将代理保存到内联 proxies，不复制本地文件到服务器。服务器上的多个文件可使用 proxyfiles 路径列表。文件内容变化后需要保存或重载配置。

| proxy_strategy | 调度行为 |
| --- | --- |
| affinity | 默认；同一会话固定首选节点，无会话时轮询 |
| sticky_round_robin | 会话固定轮询；新会话均分至固定会话数最少的健康代理，平局轮询；同会话保持分配，节点故障或冷却时转移并记住新节点 |
| round_robin | 每个请求轮换首选节点，不使用会话固定 |
| random | 每个请求随机选择首选节点，不使用会话固定 |
| least_connections | 从健康且不在冷却期的节点中，优先使用当前连接最少的节点，平局轮询 |

匿名通道在代理节点间调度。付费 Zen/Go 通道在 Key 节点间调度，每个 Key 继续使用其绑定代理；并不把每个 Key 复制到每个代理。首选节点失败后沿用原版健康检查、冷却与故障转移。动态池保持原有新连接与重复重试语义。

会话固定轮询为匿名、Zen、Go 三个通道分别维护会话分配。会话均衡按代理统计而非 Key 数量，避免某代理绑定多个 Key 时获得更多会话。重试转移立即更新会话的后续首选节点；恢复后的节点优先接收新会话，健康会话继续保持分配。代理表展示固定会话数与进程累计迁移次数。空闲 30 分钟释放会话，每个通道最多保留 20,000 个分配，超出时淘汰最久未使用的分配；进程重启清空，热重载保留仍存在的节点分配。没有会话 ID 的后台请求按普通轮询执行。

概览的请求数、成功率、延迟、Token 用量、趋势与请求分布，以及 API Key 用量，以 Asia/Singapore（UTC+8）的本日 00:00 为起点；原 last_hour API 字段保留。今日趋势按 15 分钟汇总。原版延迟直方图精度不变。

实时并发区分客户端请求与流式响应阶段，显示今日峰值。代理表显示当前连接以及今日上游尝试/成功/失败；一次客户端请求可能触发多次上游尝试。代理连接从发起上游请求计数，持续到响应体消费完成或关闭，包含模型发现和健康检查等后台流量。尝试成功按上游尝试的响应结果统计；最终流式错误计入请求成功率。

所有统计均为进程内存数据，热重载保留、进程重启清零。概览统计周期提示可查看实际采集起点。今日聚合使用完整分钟桶，不受诊断明细环形缓冲区最多返回 500 条的限制。跨午夜正在执行的请求计入新一天峰值，完成请求及其 Token 归入完成时所属日期。

新增管理接口 POST /api/proxies/parse 只解析文件，不保存配置，沿用管理会话及 CSRF 校验。代理 URL 返回给导入它们的管理员用于编辑，响应禁用缓存；状态及日统计使用指纹标识，避免代理认证信息泄漏和同地址不同账号混算。
